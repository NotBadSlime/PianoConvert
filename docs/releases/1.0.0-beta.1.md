# PianoConvert 1.0.0 Beta 1

Windows 10 / 11 x64 预发布版。

- 全新青绿色钢琴应用图标，统一用于程序窗口、任务栏与安装包。
- 温迪弹奏里拉琴的背景插画，配合浅色、深色主题自动调整遮罩，保持文字清晰。
- 青绿色按钮和强调色，保留文件拖入、转换、预览与历史记录操作。
- 安装包版本为 `1.0.0-beta.1`，Windows 数字版本为 `1.0.0`。
- Release 标记为预发布，并提供 `SHA256SUMS.txt` 校验文件。

下载 `PianoConvertSetup-1.0.0-beta.1.exe` 后运行安装。识别功能和模型沿用现有版本；扫描件和截图的识别结果仍应对照原谱检查。

本地便携目录中的 `PianoConvert.exe` 需与同级 `_internal` 文件夹一起保留。
