# 原神键盘谱（MIDI / MusicXML → 数字谱 + 键位谱）

日期：2026-09-21  
状态：已批准  
版本：0.3.0

## 背景

0.2.0 已能把音频转成 MIDI 和 MusicXML。用户还要把谱面对成原神风物之诗琴的键盘谱：自动对齐 C 大调、没有黑键、音域 C3–C6、三排。写法对齐「指尖旋律」一类常见谱：数字谱和电脑键位谱结构完全一致，只做 `+1 → Q` 这种替换。空格表示停顿，`/` 表示小节。

用户会从本机单独选 MIDI 或 MusicXML 来转，不一定先走音频转录。多音轨必须先对齐到同一条时间线；起点只差几毫秒的音当成和弦，用括号一起按。

## 目标

1. 音频转换成功写出 MIDI 之后，额外写出一份 `{stem}_键盘谱.txt`。
2. 主窗口可单独选择 `.mid` / `.midi` / `.musicxml` / `.xml`，跳过转录，只出键盘谱。
3. 一份 txt 里两段谱：**数字谱**和**键盘谱**。空格、`/`、括号位置相同，仅记号不同。
4. 所有非打击乐轨合并到一条时间线；起点相差 ≤ 50ms 的音写成一组 `( )`。

## 非目标

- 按音轨各出一份谱，或在界面里对轨
- 游戏内自动演奏、按键宏
- 指法、力度、踏板、歌词
- 在应用内编辑谱面
- 生成 PDF / 图片谱
- 从 MIDI 再强迫导出 MusicXML（单独转键盘谱时不走这条）
- 让用户调节转调、聚簇窗口、音域

## 键位表

诗琴按 C 大调 21 个白键，三排。MIDI 音高 48–83（C3–B5）按下表；C6（84）及更高音按八度折进该表。

| MIDI | 音名 | 数字谱 | 键盘谱 |
|---|---|---|---|
| 48 | C3 | `-1` | `Z` |
| 50 | D3 | `-2` | `X` |
| 52 | E3 | `-3` | `C` |
| 53 | F3 | `-4` | `V` |
| 55 | G3 | `-5` | `B` |
| 57 | A3 | `-6` | `N` |
| 59 | B3 | `-7` | `M` |
| 60 | C4 | `1` | `A` |
| 62 | D4 | `2` | `S` |
| 64 | E4 | `3` | `D` |
| 65 | F4 | `4` | `F` |
| 67 | G4 | `5` | `G` |
| 69 | A4 | `6` | `H` |
| 71 | B4 | `7` | `J` |
| 72 | C5 | `+1` | `Q` |
| 74 | D5 | `+2` | `W` |
| 76 | E5 | `+3` | `E` |
| 77 | F5 | `+4` | `R` |
| 79 | G5 | `+5` | `T` |
| 81 | A5 | `+6` | `Y` |
| 83 | B5 | `+7` | `U` |

C6 折到 C5，因此数字谱是 `+1`，键盘谱是 `Q`。没有第二十二个键。

## 记谱规则

同一事件流渲染两次。

单音：`+1` / `Q`，不加括号。  
和弦：按音高低到高、括号内不加空格。例：C4+E5 → `(1+3)` / `(AE)`；C3+E5 → `(-1+3)` / `(ZE)`。  
同组里相同音高只留一个。

分隔：

- 相邻发声事件之间一个空格。
- 停顿：事件间隔 ≥ 半拍时，每完整一拍再多一个空格（最多再加 4 个）。空拍不写成 `0`。
- 小节线：` / `（空格、斜杠、空格）。拍号取文件里的，没有则 4/4。
- 每 4 小节换行，方便阅读。

文件形态：

```text
# <歌名>
# 1=C  原神风物之诗琴  C3–C6 三排白键

【数字谱】
(+3-1) 1 2 3 / 5 6 7 +1 /

【键盘谱】
(EZ) A S D / G H J Q /
```

两段除标题行外，token 数量、空格、`/`、换行必须一致。

## 转换算法

模块：`app/keyboard_score.py`。界面和 `convert` 只调用它，不自己算音高。

输入：音符列表 `(pitch, start_sec, end_sec)` + 拍号 + 每拍秒数。  
MIDI 用 `pretty_midi` 读，跳过 `is_drum` 和通道 10。MusicXML 用 `music21` 读，跳过无音高的打击乐。多轨/多声部全部摊平，只用绝对开始时间。

步骤（顺序固定）：

1. **收集**：所有 pitched 音符。没有音符则失败：「没有可转换的音符」。
2. **转调**：试移位 0–11 半音，选落在 C 大调白键（音类 0,2,4,5,7,9,11）最多的那个。并列时取绝对移位更小的；再并列取非负的。
3. **去黑键**：剩下的升降音就近收到白键，距离相同则往上：C#→D、D#→E、F#→G、G#→A、A#→B。
4. **折音域**：低于 C3（48）每次 +12，高于 B5（83）每次 −12，直到落在 48–83。C6 因此变成 C5。
5. **和弦聚簇**：按 `start` 排序。若 `note.start - cluster[0].start ≤ 0.050` 秒，并入当前组和弦（跨轨也算）。组时戳取组内最早 `start`。组内按音高升序，去重。
6. **排版**：用拍号和速度把组放到小节里，按记谱规则写出数字谱，再按键位表替换成键盘谱。

速度：取文件第一个 tempo；没有则按 120 BPM，四分音符为一拍。拍号取文件第一个；没有则 4/4。v1 整曲只用这一个拍号，不中途换拍。

50ms 窗口作用在**原始开始时间**上，不先量化再聚簇，避免几毫秒的轨间误差被量化拆开。

## 架构

| 单元 | 职责 |
|---|---|
| `app/keyboard_score.py` | 读 MIDI/MusicXML → 转调/去黑键/折音域/聚簇 → 文本 |
| `app.convert` | 音频流程在写出 MIDI 后调用键盘谱；另提供 `run_score` 给直接选谱 |
| `app.history` | 增加可选字段 `keyboard_path`；旧记录缺字段当空字符串 |
| `app.ui.main_window` | 第二个选文件按钮、拖放谱面、历史「打开键盘谱」 |

`ConvertResult` 增加 `keyboard_path`。音频失败（没 MIDI）不写键盘谱。MusicXML 导出失败时，只要 MIDI 在，仍从 MIDI 出键盘谱。

读历史必须能吞掉缺 `keyboard_path` 的旧 JSON（当成 `""`）。`load_items` 和主窗口刷新都走同一套构造，禁止 `HistoryItem(**row)` 直接解包导致旧记录崩溃。

## 界面

单窗口不变。转换区两个入口：

- **选择音频文件**：钢琴 / 其他乐器可见。「开始转换」走现有转录，产物为 MIDI + MusicXML + 键盘谱。
- **选择 MIDI / MusicXML**：乐器单选隐藏。「转换为键盘谱」走 `run_score`，不转录。

后一次选择覆盖当前文件。拖放：音频或谱面，以后缀分流。进行中禁用两个选择按钮和乐器切换。

历史：

- `kind`：`piano` / `other` / `score`。`score` 显示为「键盘谱」。
- 四个按钮：打开 MIDI、打开 MusicXML、打开键盘谱、打开文件夹。
- 对应路径为空或不存在则禁用该按钮。旧记录没有 `keyboard_path` 时「打开键盘谱」禁用。
- 单独转谱：从 MIDI 来则 MusicXML 按钮禁用；从 MusicXML 来则 MIDI 按钮禁用。

部分成功旁注区分：仅 XML 失败写「谱面导出失败」；仅键盘谱失败写「键盘谱导出失败」。

## 单独转谱流程

1. 后缀必须是 `.mid` / `.midi` / `.musicxml` / `.xml`，文件存在。否则弹提示，不写历史。
2. 在 `文档\PianoConvert\Output\<stem>_<YYYYMMDD-HHMMSS>\` 建目录。
3. 把源文件复制进去。
4. 写出 `<stem>_键盘谱.txt`。
5. 历史 `kind=score`，`status=success`，`keyboard_path` 指向 txt。源是 MIDI 则 `midi_path` 指向目录里的副本、`musicxml_path` 为空；源是 MusicXML 则相反。

取消：删掉本次目录，不写历史。

## 音频流程增量

在现有「写入 MIDI → 写入 MusicXML」之后增加「写入键盘谱」。进度文案可加一句「写入键盘谱」。

状态：

| MIDI | MusicXML | 键盘谱 | status |
|---|---|---|---|
| 有 | 有 | 有 | success |
| 有 | 缺任一 | 有或无 | partial |
| 无 | — | — | failed |

键盘谱失败不删除已写出的 MIDI / MusicXML。

## 错误处理

| 情况 | 行为 |
|---|---|
| 谱面里没有音符 | 失败 + 「没有可转换的音符」 |
| MIDI/MusicXML 损坏读不出来 | 失败 + 「无法读取这个乐谱文件」 |
| 键盘谱写出失败（磁盘等） | 音频路径：partial + 「键盘谱导出失败」；单独转谱：failed + 「无法写入输出目录」 |
| 未选文件 | 开始按钮保持禁用 |

## 测试

最少覆盖：

1. 键位：C4→`1`/`A`，C5→`+1`/`Q`，C3→`-1`/`Z`，C6→`+1`/`Q`。
2. 黑键：F#4 去黑键后为 `5`/`G`。
3. 转调：全是 D 大调白键的音列，转完应对到 C 大调对应阶名。
4. 聚簇：三轨 1.000 / 1.012 / 1.020 秒的 C4 E4 G4 → `(135)` / `(ADG)`；间隔 80ms 的两音不是和弦。
5. 排版：4/4 下一小节四个四分音，数字谱与键盘谱的空格和 `/` 一致。
6. `run_score`：小 MIDI 写出含「【数字谱】」「【键盘谱】」的 txt。
7. 历史：缺 `keyboard_path` 的旧 JSON 能加载；该行按钮禁用。
8. UI（offscreen）：选 `.mid` 后乐器单选隐藏，主按钮文案为「转换为键盘谱」。

不把长音频端到端转录纳入默认 CI。
