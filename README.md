# PianoConvert 使用说明

PianoConvert 是一个 Windows 小软件。你给它一首歌，或者一份现成的谱，它帮你做成原神里风物之诗琴能弹的键盘谱。

不用懂编程。装好就能用。

它能做这几件事：

- 一首歌的录音，转成 MIDI、五线谱，以及诗琴键盘谱
- 已经有 MIDI 或 MusicXML，直接做成键盘谱
- 一份印刷五线谱的 PDF，尽量认成键盘谱（认错的可能比较大，下面会说）

---

## 1. 怎么安装、怎么打开

1. 打开 [下载页面](https://github.com/NotBadSlime/PianoConvert/releases)。
2. 下载最新的 `PianoConvertSetup-0.5.2.exe`。
3. 双击安装包，一路下一步。想在桌面放图标，就勾上那个选项。
4. 从开始菜单或桌面打开 **PianoConvert**。

请用 64 位 Windows。

打开之后，窗口最底下如果写着「使用 CPU，会比较慢」，表示这次用电脑自己算，钢琴歌要多等几分钟，这是正常的。电脑有 NVIDIA 显卡的话，可以改成用显卡，见下面「用显卡会更快」。

---

## 2. 窗口分成两块

**上面**用来选文件、开始转换。

**下面**是「转换记录」，以前转过的都在这里，点按钮就能打开结果。

文件也可以直接拖进窗口，和点按钮选文件是一样的。

---

## 3. 上面每个按钮是干什么的

### 选择音频文件

选电脑里的一首歌。能选这些格式：`.mp3`、`.wav`、`.flac`、`.ogg`、`.m4a`。

选好后，右边会出现文件名，下面出现「乐器类型」。大按钮上写的是 **开始转换**。

转完会得到三样东西：

- **MIDI**：给播放器、作谱软件用的音乐文件
- **MusicXML**：没压缩的五线谱文件，名字以 `.musicxml` 结尾。用 MuseScore 这类软件能打开看谱
- **键盘谱**：一个 txt，里面是诗琴的数字和电脑按键

### 选择 MIDI / MusicXML

你手里已经有谱，就走这里，不用再从录音转一遍。能选 `.mid`、`.midi`、`.musicxml`、`.mxl`、`.xml`。

选好后，「乐器类型」会消失，大按钮变成 **转换为键盘谱**。结果里主要是键盘谱，另外会把你选的原文件复制一份放在一起。

这里说的 MusicXML，是五线谱的一种通用写法，不是某一种固定的文件名。常见就这两种，**两种都能直接拿来转键盘谱**：

- **`.musicxml`**：谱本身，没压缩。用记事本打开，能看到一大段文字。本软件从歌曲转出来的五线谱就是这种。有的软件会把它存成 `.xml`，只要里面真的是乐谱，这里也能选。
- **`.mxl`**：同一份谱装进了压缩包，文件更小。MuseScore 导出时经常是这个。它不是另一种谱，选它就行，不用先解压。

### 选择 PDF 乐谱

选一份五线谱 PDF，直接做成键盘谱。大按钮也是 **转换为键盘谱**。

这个功能是在「看图认谱」，**经常会认错**。字印得清楚的五线谱还好一点。拍照、扫描件、手写、简谱、吉他谱，很容易认成别的音。转完一定要对照原来的谱再弹。

第一次认 PDF 要联网，软件会去下载认谱用的模型。下完以后可以断网用。

### 乐器类型

只有选了歌曲录音才会出现。

- **钢琴**：录音里主要是钢琴时选这个，一般更准。
- **其他乐器**：吉他、哼唱、别的乐器选这个。

拿不准就听一下：像钢琴就选钢琴，否则选其他乐器。选错了也能转出来，只是音容易偏、杂音会多。

### 用显卡会更快

这一项也是只有选了歌曲录音才出现。MIDI、MusicXML、PDF 用不上它。

- **CPU**：用安装包里自带的办法算，不用再下载。比较慢。
- **GPU**：用 NVIDIA 显卡算，通常快很多。第一次选它，软件会告诉你还要另外下载大约 2.3 GB，并写出要装到哪个文件夹。点 **下载 GPU 组件** 以后，进度条会显示下了多少，例如「正在下载 PyTorch  43%（820 MB / 1.85 GB）」。可以中途点 **取消下载**，下次会接着下，不用从头再来。

也可以点 **打开安装脚本**，自己运行那个脚本。脚本窗口里同样会显示下载进度。装好之后，再选一次 **GPU** 就可以了。

没有 NVIDIA 显卡就保持 **CPU**。

### 开始转换

选好文件再点。转的过程中，这个按钮变成 **取消**，再点一次就停掉，这次不会留下结果。

还没选文件时，按钮是灰的，点不了。

### 进度条

蓝条往前走的时候，下面的字会变成「读取音频」「转录」「写入 MIDI」这类进度。走完会显示「完成」。失败的话，会用短短一句话告诉你原因。

## 4. 第一次可以这样用

**我只有一首歌**

1. 点「选择音频文件」，选那首歌。
2. 像钢琴就选「钢琴」，否则选「其他乐器」。
3. 点「开始转换」，等它走完。
4. 到下面的记录里打开结果。

**我已经有 MIDI 或五线谱文件**

1. 点「选择 MIDI / MusicXML」。MIDI 选 `.mid`。五线谱选 `.musicxml`、`.mxl`，或里面确实是乐谱的 `.xml`。
2. 点「转换为键盘谱」。
3. 在记录里点「打开键盘谱」。

**我只有一份五线谱 PDF**

1. 点「选择 PDF 乐谱」。
2. 点「转换为键盘谱」。
3. 打开键盘谱之后，对照原来的 PDF 看有没有认错。

## 5. 下面的转换记录

每转完一次，最上面会多一行。关掉软件再打开，这些记录还在。

一行上能看到：歌名、是钢琴还是其他乐器还是直接转的谱、完成时间、成功还是失败。

歌名下面有四个按钮：

| 按钮 | 点了会怎样 |
|---|---|
| **打开 MIDI** | 用电脑默认的程序打开 MIDI |
| **打开 MusicXML** | 打开没压缩的五线谱（`.musicxml`）。想看谱，可以装 [MuseScore](https://musescore.org/) |
| **打开键盘谱** | 用记事本打开 txt |
| **打开文件夹** | 打开这一次结果所在的文件夹，方便你复制、发给别人 |

某个文件没生成时，对应的按钮是灰的。比如这次只做了键盘谱，就没有五线谱，「打开 MusicXML」点不了。

如果提示「文件不在了」，多半是你把结果挪走或删了，再转一次就行。

三种结果：

- **成功**：该有的文件都有了。
- **部分成功**：MIDI 有了，但五线谱或键盘谱有一样没写成。能打开的按钮还可以点。
- **失败**：这次没有能用的结果，旁边会写原因。

---

## 6. 文件存在哪

每次转换都会新建一个文件夹，不会盖掉上一次的：

`文档\PianoConvert\Output\歌名_日期时间\`

例如：`C:\Users\你的用户名\Documents\PianoConvert\Output\小星星_20260921-153000\`

## 7. 键盘谱怎么看、怎么弹

诗琴是 C 大调，只有白键，没有黑键。能弹的音从 **C3 到 B5**，一共 21 个音，排成三排。最高是 B5（高音的 Si），**没有 C6 这个音**。

打开 txt，能看到上下两段。两段的空格、斜杠、括号位置完全一样，只是写法不同：上面是数字，下面是电脑键盘。

```text
【数字谱】
(+3-1) 1 2 3 / 5 6 7 +1 /

【键盘谱】
(EZ) A S D / G H J Q /
```

**三排分别按什么**

| 哪一排 | 实际的音 | 数字 | 电脑键 |
|---|---|---|---|
| 下面一排，低音 | C3 到 B3，低音 Do 到 Si | `-1` `-2` `-3` `-4` `-5` `-6` `-7` | `Z` `X` `C` `V` `B` `N` `M` |
| 中间一排 | C4 到 B4，中音 Do 到 Si | `1` `2` `3` `4` `5` `6` `7` | `A` `S` `D` `F` `G` `H` `J` |
| 上面一排，高音 | C5 到 B5，高音 Do 到 Si | `+1` `+2` `+3` `+4` `+5` `+6` `+7` | `Q` `W` `E` `R` `T` `Y` `U` |

最好记的三个音：

- `1` 是中音 Do，按 `A`
- `+1` 是高音 Do，按 `Q`
- `-1` 是低音 Do，按 `Z`

**谱上的符号**

- **空格**：离下一个音还要再等一会儿。空格越多，等得越久。音按下去要按多久，谱上不写。
- **`/`**：按开头的拍号，过完一小节约等于换气。4/4 就是数满 4 拍画一条。
- **`( )`**：括号里的音要一起按。差不多同时响的音（相差不超过 0.05 秒）会收进同一个括号。

**节奏是怎么被改写成空格的**

软件不照搬 MIDI 里的符值，只看每个音是什么时候开始响，再换成空格。以最常见的 120 拍、4/4 为例，一拍大约半秒：

| 两个音隔了多久 | 中间几个空格 | 听起来 |
|---|---|---|
| 大约半拍，或更短但不是同时 | 1 个 | 挨得很近 |
| 大约 1 拍 | 2 个 | 常说的一拍一个音 |
| 大约 2 拍 | 3 个 | 中间空一拍 |
| 大约 3 拍 | 4 个 | 中间空得更久 |
| 大约 4 拍或更久 | 5 个 | 再久也不再加空格 |

空格按拍数算，不按墙上的秒数。120 拍时一拍大约半秒；后面如果变成 60 拍，一拍就变成大约一秒，但谱上「隔一拍」仍是两个空格。

有的 MIDI 音没有刚好卡在拍上，几个音轨也会差那么一点点。键盘谱会把差得不多的音收到同一拍上：差不多半拍以内的，算同一个音或同一个和弦；差到半拍以上的，仍然分开。这样排的只有键盘谱。歌曲转出来的 MIDI、五线谱，以及你自己选的原文件，都保持原样，不按这个规则去改。

歌中间变速或换拍号，从那一小节起跟着变，并在数字谱和键盘谱的同一位置标出来。例如 `〔60拍〕` 表示这里改成每分钟 60 拍，`〔3/4〕` 表示从这里起一小节只有 3 拍。

举例。开头 120 拍、4/4，四个音每拍一个：中音 Do、Re、Mi、Fa。下一小节改成 60 拍，还是每拍一个音。转出来是：

```text
【数字谱】
1  2  3  4 / 〔60拍〕1  2  3  4 /

【键盘谱】
A  S  D  F / 〔60拍〕A  S  D  F /
```

后面虽然更慢，音和音之间仍是两个空格，因为还是隔一拍。`〔60拍〕` 提醒你从这里放慢。

如果第二小节改成 3/4，而不是变速，三个音之后就画 `/`：

```text
【数字谱】
1  2  3  4 / 〔3/4〕5  6  7 /

【键盘谱】
A  S  D  F / 〔3/4〕G  H  J /
```

另一个例子。速度不变，120 拍、4/4。第一小节每拍一个音。第二小节开头 Do 和 Mi 几乎一起按，再空大约三拍，到 Sol。转出来是：

```text
【数字谱】
1  2  3  4 / (13)    5 /

【键盘谱】
A  S  D  F / (AD)    G /
```

第一小节里，音和音之间是两个空格，表示隔了一拍。`(13)` 和 `(AD)` 是一起按的 Do 和 Mi。它和后面的 `5` / `G` 之间是四个空格，表示隔了大约三拍。那条 `/` 是第一小节结束。

曲子如果不是 C 调，软件会自动挪到 C 调的白键上，这样诗琴才能弹。比 C3 更低、或比 B5 更高的音，会整组挪进这 21 个音里面。所以特别高的音不会单独占一个新键，C6 也不会出现在谱上。

一首 MIDI 里如果有旋律、伴奏好几条，软件会按时间排到同一份谱上。几乎同时响的音，会放进同一个括号，当成和弦一起按。

## 8. 遇到问题先看这里

**点了开始转换没反应？**  
先看右边有没有文件名。没选文件时，按钮是灰的。

**钢琴歌转得很慢？**  
看窗口最底下。写着「使用 CPU，会比较慢」时，有 NVIDIA 显卡就可以改成 **GPU**，按提示把显卡组件下完再转。没有显卡就多等几分钟。同一首歌转一次就够了，结果会留在下面的记录里。

**转出来的音不准，杂音很多？**  
换一下「钢琴 / 其他乐器」再转一次。录音太吵、人声太重时，也会差一点。

**键盘谱和原曲不是一个调？**  
这是故意的。诗琴按 C 调白键弹，软件会把曲子挪到最好按的位置。

**括号里音太多，按不过来？**  
原曲的和弦叠在一起时就会这样。可以先按括号里最高的几个音，或者点「打开 MIDI」先听一遍，再决定怎么简化。

**能一次转很多首吗？**  
一次一首。这一首结束后，再选下一首。

**要一直联网吗？**  
歌曲、MIDI、MusicXML 不用联网。PDF 第一次要联网下载认谱模型，下完可以断网。选 GPU 时，那一次下载显卡组件也要联网。
