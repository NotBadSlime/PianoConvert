# PianoConvert 使用说明

PianoConvert 是给 Windows 用户用的小工具。你可以把一首歌的音频转成乐谱，也可以把 MIDI、MusicXML 或 PDF 五线谱转成**原神风物之诗琴键盘谱**。音频转换不需要联网。

适合：想把喜欢的曲子变成可弹的谱、或在原神里按键盘谱演奏的人。不需要懂编程。

---

## 1. 安装和打开

1. 打开 [下载页面](https://github.com/NotBadSlime/PianoConvert/releases)。
2. 下载最新的 `PianoConvertSetup-0.4.0.exe`。
3. 双击安装包，按提示下一步（可勾选桌面快捷方式）。
4. 从开始菜单或桌面打开 **PianoConvert**。

需要 64 位 Windows。电脑没有独立显卡时，窗口最底下可能写「使用 CPU，会比较慢」——这是正常的，钢琴音频转换会多等几分钟。

---

## 2. 窗口长什么样

窗口分上下两块：

| 区域 | 作用 |
|---|---|
| **上半部分（转换区）** | 选文件、选类型、开始转换 |
| **下半部分（转换记录）** | 以前转过的结果，点按钮打开文件 |

也可以把文件直接**拖进窗口**，效果和点按钮选文件一样。

---

## 3. 上半部分：每个按钮干什么

### 选择音频文件

从电脑里选一首歌。支持：`.mp3`、`.wav`、`.flac`、`.ogg`、`.m4a`。

选好后，右边会显示文件名。这时会出现「乐器类型」，主按钮是 **开始转换**。

转完会得到三样东西：

- **MIDI**（`.mid`）：能用播放器或打谱软件打开
- **MusicXML**（`.musicxml`）：五线谱交换格式，可用 MuseScore 等软件打开
- **键盘谱**（`_键盘谱.txt`）：原神诗琴用的数字谱 + 电脑键位

### 选择 MIDI / MusicXML

如果你已经有乐谱文件，不必再从音频转一遍。点这个按钮，选 `.mid`、`.midi`、`.musicxml` 或 `.xml`。

选好后，「乐器类型」会藏起来（用不上），主按钮变成 **转换为键盘谱**。只会生成键盘谱，并在结果文件夹里放一份你选的原文件。

### 选择 PDF 乐谱

选一份五线谱 PDF，直接转成键盘谱。主按钮同样是 **转换为键盘谱**。

识别用的是开源项目 [homr](https://github.com/liebharc/homr)。**准确度有限**：清晰的印刷五线谱比较好用；扫描件、拍照、手写、简谱、吉他谱经常认错。转完请对照原谱再弹。第一次识别需要联网，用来下载识别模型；之后可以离线。

### 乐器类型（只有选了音频才会出现）

- **钢琴**（默认）：录音里主要是钢琴时选这个，效果通常更好。
- **其他乐器**：吉他、人声哼唱、其他器乐时选这个。

选错也能转，但音准和杂音可能差一些。拿不准时：听起来像钢琴就选钢琴，否则选其他乐器。

### 开始转换 / 转换为键盘谱

选好文件后点它。转换进行中，这个按钮会变成 **取消**。再点一次就会停掉，这次的结果不会保存。

没选文件时按钮是灰的，点不了。

### 进度条和下面那句说明

条会往前走，下面的字会依次变成「读取音频」「转录」「写入 MIDI」等。转完显示「完成」。失败时会看到简短原因。

---

## 4. 第一次转换可以怎么走

**我只有一首 mp3**

1. 点「选择音频文件」，选那首歌。
2. 乐器选「钢琴」或「其他乐器」。
3. 点「开始转换」，等进度走完。
4. 到下面的「转换记录」里打开结果。

**我已经有 MIDI 或 MusicXML**

1. 点「选择 MIDI / MusicXML」。
2. 点「转换为键盘谱」。
3. 在记录里点「打开键盘谱」。

---

## 5. 下半部分：转换记录

每转完一次，这里会多一行，最新的在最上面。关掉软件再打开，记录还在。

一行里能看到：歌名、类型（钢琴 / 其他乐器 / 键盘谱）、完成时间、成功或失败。

右边四个按钮：

| 按钮 | 打开什么 |
|---|---|
| **打开 MIDI** | 用系统默认程序打开 `.mid` |
| **打开 MusicXML** | 打开五线谱文件（可装 [MuseScore](https://musescore.org/) 来看谱） |
| **打开键盘谱** | 用记事本打开 txt，里面是数字谱和电脑键位 |
| **打开文件夹** | 打开这次结果所在的文件夹，方便复制、分享 |

某个文件没有生成时，对应按钮会变灰。例如只转了键盘谱，就没有 MusicXML，「打开 MusicXML」点不了。

如果提示「文件不在了」，多半是结果被你挪走或删了，需要重新转换。

**成功 / 部分成功 / 失败**

- **成功**：该有的文件都有了。
- **部分成功**：MIDI 出来了，但五线谱或键盘谱有一样没写成。能打开的按钮仍可用。
- **失败**：没有可用结果，旁边会写原因。

---

## 6. 结果文件在哪

每次转换都会新建一个文件夹，不会覆盖上次的：

`文档\PianoConvert\Output\歌名_日期时间\`

例如：`C:\Users\你的用户名\Documents\PianoConvert\Output\小星星_20260921-153000\`

---

## 7. 键盘谱怎么看、怎么弹

打开 txt 后能看到两段，**上下结构完全一样**，只是记号不同：

```text
【数字谱】
(+3-1) 1 2 3 / 5 6 7 +1 /

【键盘谱】
(EZ) A S D / G H J Q /
```

上面给手机端 / 按数字对照，下面给电脑键盘。空格、斜杠、括号的位置两边一致。

**三排键位（原神风物之诗琴，C 大调，没有黑键）**

| 高低 | 数字怎么写 | 电脑键盘 |
|---|---|---|
| 低音（下面一排） | `-1` `-2` `-3` `-4` `-5` `-6` `-7` | `Z` `X` `C` `V` `B` `N` `M` |
| 中音（中间一排） | `1` `2` `3` `4` `5` `6` `7` | `A` `S` `D` `F` `G` `H` `J` |
| 高音（上面一排） | `+1` `+2` `+3` `+4` `+5` `+6` `+7` | `Q` `W` `E` `R` `T` `Y` `U` |

对照：`1` = Do = `A`，`+1` = 高音 Do = `Q`，`-1` = 低音 Do = `Z`。

**符号**

- **空格**：停一会儿再按下一个。空格越多，停得越久。
- **`/`**：一小节结束，换一口气，进入下一小节。
- **`( )`**：括号里的音要一起按。例如 `(135)` 就是中音 Do、Mi、Sol 同时按，电脑上就是 `(ADG)`。

软件会自动把曲子转到 C 大调白键上（诗琴没有黑键）。太高或太低的音会按八度收到 C3–C6 这三排里。

如果 MIDI 里有好几条音轨（旋律、伴奏等），会先对齐到同一条时间上再写成一份谱；几乎同时响的音会收进同一个括号，当作和弦一起按。

## 8. 常见问题

**点了开始转换没反应？**  
先看有没有选出文件名。没选时按钮是灰的。

**钢琴转换很慢？**  
没有独立显卡时会用 CPU，等几分钟是正常的。一首歌只转一次即可，结果会留在转换记录里。

**转出来的音不准、很多杂音？**  
换一下「钢琴 / 其他乐器」再转一次。录音太吵、人声太重时，识别也会差一点。

**键盘谱和原曲差一个调？**  
这是故意的：诗琴按 C 大调白键弹，软件会把原曲挪到最接近、最好弹的白键位置。

**括号里怎么那么多音、按不过来？**  
原曲和弦或音轨叠在一起时会这样。可以先弹括号里最高的几个音，或只用「打开 MIDI」听一下再决定怎么简化。

**支持一次转很多首歌吗？**  
一次转一首。上一首结束后，再选下一首即可。

**要联网吗？**  
音频、MIDI、MusicXML 转换不需要联网。PDF 识别第一次要联网下载模型，下载完成后可以离线。
